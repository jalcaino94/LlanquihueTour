## 📘 Descripción general del sistema

# LlanquihueTour
Proyecto académico en Java que digitaliza la gestión de la agencia de turismo Llanquihue Tour. Desarrollado aplicando principios de Programación Orientada a Objetos (POO) como composición y herencia, garantizando un código limpio, estructurado y reutilizable.

## 🧱 Estructura general del proyecto

📁 src/
├── app/         # Clase principal que actúa como motor del programa (Main.java)
└── model/       # Clases de dominio y plantillas de datos:
                 # - Persona.java (Clase Base)
                 # - Empleado.java (Clase Heredada)
                 # - Direccion.java (Clase de Composición)
